# My App Install Page

A free, mobile-first PWA installation landing page.

## Run locally

Open `index.html` in a local web server. Service workers and PWA installation require HTTPS (GitHub Pages provides this automatically) or localhost.

## Customize

- Change the app name and text in `index.html` and `manifest.webmanifest`.
- Replace `icon.svg` with your own authorized logo.
- Update the download count in `index.html`.

## Deploy for free

Enable GitHub Pages in the repository settings and select the `main` branch as the source.
